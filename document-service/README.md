# Document Service - README\n\nThis repository contains the source code for a document management service built with Go and gRPC.\n\nThe application provides functionality to upload, confirm, list, and manage documents using secure protocols.

## Features\n- Upload and store documents via gRPC API\n- Role-based access control (RBAC) between clients and officers\n- Integration with PostgreSQL database for document storage\n- Object storage integration through MinIO\n- Versioned protocol buffer definitions for service contracts\n
## Directory Structure\n\n- `cmd/document/` - Command-line entry point for the application\n- `internal/` - Core application logic including adapters, use cases, domain models, and configuration\n- `migrations/` - SQL scripts to create database schema\n- `proto/` - Protocol buffer definitions for gRPC services\n- `deployments/docker/` - Docker Compose setup for local development environment (MinIO + PostgreSQL)\n- `buf.yaml`, `buf.gen.yaml` - Configuration files for buf tool (protobuf code generation)\n- `go.mod` - Go module configuration file\n
## Setup Instructions\n1. Clone this repository to your local machine\n2. Install required dependencies: Go, Docker, PostgreSQL, MinIO\n3. Create a database and configure connection strings in internal/config/config.go\n4. Start the development environment using docker-compose:\n   \"docker-compose up -d\"\n5. Run the document service with go run cmd/document/main.go\n6. Use gRPC client to interact with the service through defined endpoints
